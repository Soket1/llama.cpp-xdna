# Готовые NPU-кернелы (XDNA 2, 8 колонок)

Скомпилированные `.xclbin` + `.insts` для **Llama-3.2-1B-Instruct**. Лежат в репозитории,
чтобы запуск не требовал AIE-тулчейна.

```powershell
$env:GGML_XDNA_CACHE_DIR = "$PWD\npu_kernels_win_8col"
```

Без этой переменной бэкенд смотрит в свой каталог по умолчанию
(`%LOCALAPPDATA%\ggml-xdna\xclbin\` на Windows, `~/.cache/ggml-xdna/xclbin/` на Linux),
где пусто — и попытается компилировать сам.

## Как читать имена

Имя — это ключ кэша: операция + геометрия. Модель в нём не упоминается, поэтому таблица ниже.

| Поле | Значение |
|---|---|
| `K` | длина редукции (вход GEMV). Для проекций = `n_embd` |
| `N` | длина выхода |
| `H` | размер FFN-скрытого слоя |
| `sl` | длина KV-кэша, под которую собран кернел |
| `d` | `head_dim` |
| `kv` | число KV-голов, `ag` | q-голов на одну KV (GQA) |
| `g32` | размер группы квантизации Q4_0 |
| `4col`/`8col` | сколько колонок NPU занимает |
| `bf16` | bf16-веса; без пометки — int4 |

Кернел подхватывается, только если геометрия тензоров в графе совпала с зашитой в имя.
Для слитого слоя проверка жёсткая (`ggml-xdna.cpp`): `E=2048, H=8192, head_dim=64,
attn_group=4, num_kv=8, num_q=32`. Не совпало — молча идёт откат на CPU/пооперационный путь.

## Что чему соответствует в Llama-3.2-1B

`n_embd=2048`, `n_ff=8192`, 16 слоёв, 32 q-головы / 8 kv-голов, `head_dim=64`, словарь 128256.

| Файл | Что считает |
|---|---|
| `decode_layer_f3best_K2048_H8192_sl256_d64_ag4_kv8_g32_mc_preq_vexp_vreg_dq8` | **весь decode-слой одним диспатчем** — быстрый путь |
| `qkv16_K2048_N3072_4col_g32` | слитая проекция Q+K+V (2048+512+512=3072) |
| `ffn16_2mm_K2048_N8192_4col_g32` | FFN gate+up+SiLU+mul+down на 16 тайлах |
| `decode_front_attn_K2048_N64_sl256_4col_ag4_kv8_g32` | Q-GEMV + RoPE + attention |
| `gemv_int4_v2_K2048_N2048_*` | `attn_q`, `attn_output` |
| `gemv_int4_v2_K2048_N512_*` | `attn_k`, `attn_v` (8 kv-голов × 64) |
| `gemv_int4_v2_K2048_N8192_*` | `ffn_gate`, `ffn_up` |
| `gemv_int4_v2_K8192_N2048_*` | `ffn_down` |
| `gemv_int4_v2_K2048_N3072_*` | QKV одной матрицей |
| `gemv_int4_v2_K2048_N128256_*` | `lm_head` (словарь). ⚠️ на NPU это **регресс** 28.5→23.0 т/с, по умолчанию выключено |
| `gemv_int4_*` (без `_v2`) | те же формы через кернел первой версии |
| `gemv_*_bf16_*` | те же формы для bf16-модели (не Q4_0) |

Отсюда же видно, как определить пригодность для другой модели: совпадают `n_embd`,
`n_ff` и геометрия голов — кернел подойдёт; иначе нужен свой (см. `compile.py`,
раздел «Compile.py» в [XDNA_QUICKSTART_DEV.md](../XDNA_QUICKSTART_DEV.md)).

Например, у Llama-3.2-3B `n_embd=3072` и `head_dim=128` — ни один файл отсюда не подойдёт,
и при первом запуске бэкенд соберёт новые (для этого нужен тулчейн).

## Каталоги `*_build/`

Промежуточные файлы aiecc (MLIR, объектники, логи). В `.gitignore`, пересоздаются при
каждой компиляции, удалять можно свободно.
